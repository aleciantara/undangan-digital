# Undangan Digital — Feature Roadmap

Product feature list organized by area. Tags indicate when to build and market focus.

## Legend

| Tag | Meaning |
|-----|---------|
| **MVP** | Build first — core launch scope |
| **v2** | After launch — post-MVP iteration |
| **ID exclusive** | Indonesian market differentiator |

---

## 1. Templates & design

| Feature | Description | Tags |
|---------|-------------|------|
| Template picker | Choose from multiple layouts | MVP |
| Indonesian motif themes | Batik, Parang, Kawung, Mega Mendung, Ulos patterns | MVP, ID exclusive |
| Color & font picker | Custom palette and typography | MVP |
| Envelope animation | Opening reveal on load | v2 |
| Animated motifs | Floating petals, ornaments | v2 |
| PDF export | Download printable version | v2 |
