# Undangan Digital — Feature Roadmap

Product feature list organized by area. Tags indicate when to build and market focus.

## Legend

| Tag | Meaning |
|-----|---------|
| **MVP** | Build first — core launch scope |
| **v2** | After launch — post-MVP iteration |
| **ID exclusive** | Indonesian market differentiator |

---

## 1. Templates & design

| Feature | Description | Tags |
|---------|-------------|------|
| Template picker | Choose from multiple layouts | MVP |
| Indonesian motif themes | Batik, Parang, Kawung, Mega Mendung, Ulos patterns | MVP, ID exclusive |
| Color & font picker | Custom palette and typography | MVP |
| Envelope animation | Opening reveal on load | v2 |
| Animated motifs | Floating petals, ornaments | v2 |
| PDF export | Download printable version | v2 |

---

## 2. Multi-event support

| Feature | Description | Tags |
|---------|-------------|------|
| Multiple event cards | Akad, resepsi, siraman, pengajian, midodareni | MVP, ID exclusive |
| Per-event RSVP | Guests RSVP per ceremony | MVP, ID exclusive |
| Per-event countdown | Countdown to each event | MVP |
| Venue map + Waze/Gmaps | Direct navigation links | MVP, ID exclusive |

---

## 3. Delivery & sharing

| Feature | Description | Tags |
|---------|-------------|------|
| Unique guest link | Personalized URL per guest | MVP |
| WhatsApp share | One-tap `wa.me` share button | MVP, ID exclusive |
| QR code per invite | Scan-to-open at the venue | MVP |
| Email delivery | Send and track open rate | MVP |
| SMS / WA broadcast | Bulk send via Twilio or Zenziva | v2, ID exclusive |

---

## 4. Guestlist & RSVP

| Feature | Description | Tags |
|---------|-------------|------|
| Guestlist manager | Add guests, import CSV/Excel | MVP |
| RSVP form | Attendance, plus-one, meal preference | MVP |
| RSVP dashboard | Live confirmed / declined / pending | MVP |
| Auto reminders | WhatsApp or email nudge before deadline | v2 |
| Seating chart | Assign guests to tables | v2 |

---

## 5. Engagement & social

| Feature | Description | Tags |
|---------|-------------|------|
| Wishes / comments | Guest messages with moderation | MVP |
| Background music | Upload or embed song | MVP |
| Photo gallery | Couple pre-wedding photos | MVP |
| Guest photo upload | QR scan → upload at event | v2 |
| Love story timeline | “Our journey” milestones | v2 |
| Digital gift / amplop | Bank transfer, GoPay, OVO links | v2, ID exclusive |

## 6. Admin & analytics

| Feature | Description | Tags |
|---------|-------------|------|
| Couple dashboard | Manage all invitations | MVP |
| Open & click tracking | Who opened, when | MVP |
| Publish scheduling | Go live on chosen date | MVP |
| Freemium / paid plans | Free basic, premium templates | MVP |
